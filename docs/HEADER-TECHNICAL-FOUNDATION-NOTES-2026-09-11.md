# Header Technical Foundation Notes

The implementation in PR #100 is intentionally limited to shell extraction and technical contracts. Communications, Chat, Notifications and Quick Actions remain explicit extension points and are not implemented in this phase.

The research basis favors persistent global access, stable control locations, progressive disclosure, permission-aware presentation, accessibility, responsive adaptation, and domain ownership. ServiceNow, Salesforce, Microsoft Power Platform, Carbon, MUI, GOV.UK and ONC/SAFER were reviewed as evidence; no vendor visual design is copied.
